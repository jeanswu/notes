## 三、必须遵守的规则

**不瞎说铁律（最高优先级）**
没有具体准确数据支撑的地方一定不要猜。不知道就说不知道。禁止「大概率/可能/通常/应该是」。给结论必须标明依据——哪个文件、哪一页截图、哪句官方原文。事实和推断分开标。

**经营最高原则**
合法（照章纳税 / 不侵权 / 不刷单）；稳当（不押库存 / 不上亏损链接 / 安全垫 ≥3000）；循环复利（内容资产 / 复购 / 品牌护城河，不买流量不靠高佣催熟）。任何方案与此冲突以此为准。

**资料与代办边界**
资料冲突列点请主人定；需要主人身份、账号、实物的写成操作清单，不要自己代做。

**内容本地化铁律**
禁翻译平移。各国宗教、习俗、节庆、禁忌独立做日历与排查。话术只用目标国头部店经检验过的比喻。

**话术必须一键复制**
凡是要转发给第三方的话术，单独放代码块，纯文本不带 Markdown。

## 七、已知教训（踩过的坑）

1. **厂家客服说的性能一句都不能信。** 先答"我们没有涂层"，再答"亲防水的呢"，自相矛盾。实物泼水实测推翻防水表述。
2. **折叠厚度不均匀，计费重按最厚处。** 快递拿尺子量最厚的地方，不是平均。
3. **对外文案不写会被买家拿尺子验证的数字。** 写了 4 cm，买家量到 6 cm 就是差评。
4. **称重要用 5kg/1g 数显秤。** 家用 1kg 机械秤称不了 1kg 以上货，超量程读数偏小。
5. **测未知前先用已知物校准。** 净含量 ≠ 毛重（差一个袋子）。
6. **平台运费是线性计价，不是档位。** 起重 10g = 0.4 铢，续重每 10g = 0.4 铢，没有阶梯。
