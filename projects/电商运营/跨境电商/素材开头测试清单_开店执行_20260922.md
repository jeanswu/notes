# 素材开头测试清单（开店执行·泰国35#）

> 建档 2026-09-22。依据：带货视频工作流 + 90天路线 + 外部印证（5开头小测试 / 前7天三信号）。
> 目的：**新店没单先不换品，用5个不同开头测出"哪个钩子留住泰国轿车车主"**。

## 〇、铁律（拍前先读）

1. **只变开头，其他全部一致**——同一产品、同一价格฿499、同一时长（15-20秒）、同一发布时段、同一证据镜结构。否则数据没法归因。
2. **证据镜必须实拍**：不塌/急刹不滑/承重/尺寸适配，样品真拍，禁AI伪造演示。
3. **泰语口播为初版**：所有泰语必须泰国人审校发音用词后再发，不直接发直译稿。
4. 每条只回答一个问题：**"这个开头，前3秒能不能让被塌箱/滚货坑过的轿车车主停下来？"**
5. 不追单条爆，先攒样本：一批5条，3天看数据，用赢家结构复制下一批。

## 四、判定与迭代（第3天复盘）

1. **先问"在哪掉"（5 Why纪律）**，不急着改：
   - 前3秒留存低 → 开头钩子问题 → 淘汰该开头，换同逻辑新钩子
   - 留存高、点击低 → 证据/主图问题，不是开头问题
   - 点击高、成交低 → 详情页/到手价/信任问题，回查详情首屏4问
2. **赢家定义**：前3秒留存明显领先、且带来点击的开头 → 保留，**复制它的结构**（换人物/场景/车型）做下一批，不靠投流放大。
3. **输家处理**：留存垫底的2个直接删，不反复救——把错误扼杀在成本最小时。
4. 下一批：在赢家方向上再做5条微变体，持续养同一标签。

## 六、营销内容怎么加"情绪价值"（2026-09-22主人定）

**结论：可以加、应该加，但分工明确——情绪钩子负责留人/共鸣，产品证据负责成交。**

1. **情绪放在"前3秒 + 尾段感受"，中段必须是证据**
   - 前3秒：制造共鸣/被理解感（痛点、尴尬、渴望）→ 让人停下来。
   - 中段：承重12.2kg、急刹不滑、防水、尺寸贴合等**实拍硬证据**，一个都不能省。
   - 尾段：除价格CTA外，可加一句"被理解/被照顾"的感受落点（如"后备箱清爽了，心情也不乱了"）。
2. **四种可测的情绪型开头方向**（并入A-E同一套控制变量来测，不单独开小灶）：
   - 共情痛点：把"乱、塌、尴尬"说中，让她觉得"说的就是我"。
   - 被理解：描述她的日常（接娃/买菜/通勤），传递"有人懂你的忙"。
   - 向往感：打开即整齐硬挺的画面 + "想要这种清爽"的情绪。
   - 轻松幽默：自嘲式小尴尬，降低防备（注意不贬低用户）。
   - **整理即疗愈（F方向，2026-09-22补）**：有人不开心去拼豆，有人不开心去收拾东西——**收纳整理本身就是情绪抒发、找回掌控感的方式**。画面：心情烦乱时打开后备箱，一件件归位、合上、世界变整齐；落点"收拾完，心里也清爽了"。把收纳箱从"装东西的工具"升级成"整理情绪的场景"。
3. **三条红线**：
   - ❌ 只有煽情没有产品证据 → 不成交，判废。
   - ❌ 伪造翻车/事故、夸大功效、虚假承诺 → 违规且反噬。
   - ❌ 直接翻译中文情绪文案 → 情绪点和比喻必须泰国本地化、泰国人审校。
4. **怎么判定有效**：情绪型版本与其他开头同条件比，前3秒留存是否更高、且点击/成交不掉——情绪只赢留存、不赢点击成交的，说明情绪勾住了人但产品承接不足，回中段证据。
