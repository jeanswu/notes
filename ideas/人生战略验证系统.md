# 人生战略验证系统

## 三个可用的思维模型

1. **终局反推**——写悼词、回忆录末章、临终遗憾清单三份终局文本并封存，重大决定前问："这个选择写进回忆录，是我认可的故事吗？"
2. **领先指标**——人生无法等终局数据，只能检验中间变量：精力结构、关系账户、身体、心流占比；连续恶化 = 战略被执行歪了。
3. **可逆性决策分流**——可逆决策（换工作、试方向）标准降到"不坏就行"，快进快出；不可逆决策（伤身体、背弃价值观）才配终局检验。
4. **遗产生意日**——每年固定一天重读终局文本（不许改），回答三问后裁决：继续 / 调整结构 / 重大转向（一生不超过两三次）。

## 我推翻/修正的旧认知

以前我以为人生和事业战略一样，可以靠收集足够多数据、反复论证来验证对错。现在意识到：人生没有外部裁判、没有反事实、结果滞后到无法修正——它只能"对齐"不能"验证"。真正需要管理的不是"选没选对"，而是"纠错速度"和"过程一致性"。横向扫描收集的全是二手信息，只有纵深投入产生的一手数据才能验证战略。

相关印证：[[穷查理宝典]]——"先把业务做强获得实践数据，再考虑战略转型"与本笔记"对齐而非验证"互相印证。

## 准备怎么用（具体场景 + 时间）

- 本周内：写出三份终局文本，封存（半天）。
- 每月末：15 分钟自评四个活法指标（精力结构 / 关系账户 / 身体 / 心流占比）。
- 每年固定一天：遗产生意日，重读终局文本 + 三问 + 裁决，进日历。
- 重大决策现场：先问可逆还是不可逆——可逆的快速试错，不可逆的才动用终局检验。

配套系统：[[战略哨兵系统]]（业务版，月度看板 + 季度复盘，与本笔记同构联动）。

## 原文摘录（只留真正打动我的）

> 事业的错，市场会用数据告诉你；人生的错，只有两种信号——临终的遗憾，和当下的持续违和。前者等不起，后者每月花 15 分钟就能读到。

> 三条俱在，战略大概率没跑偏——即使此刻世俗意义上它是"错的"：不觉得在熬、在变深而不只是在变老、有人因你的存在真正过得更好。
