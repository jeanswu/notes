# 发布前检查清单（每条视频逐项打勾）

> 任一项不过，不发布。

## A. 真实性（最高优先）
- [ ] 所有"证明性能"镜头（不塌/不滑/承重/防漏/泼水/尺寸）均为**样品实拍**，无 AI 伪造演示
- [ ] 痛点"翻车"开场未让本产品出假事故；如用普通箱演示已明确区分
- [ ] 视频呈现与买家实际收到的产品一致（颜色/结构/配件）

## B. 本地化
- [ ] 泰语口播已经泰国人审校发音与用词
- [ ] 形容/比喻取自《泰国本土话术库》TOP3 店铺原句，非中译泰自造
- [ ] 无脚踩产品、无摸头、无佛像/王室/政治元素
- [ ] 音乐为泰国本地热榜或无版权问题

## C. 卖点与证据
- [ ] 主打点只有一个（แข็งไม่ยุบ 硬挺不塌），其余做支撑
- [ ] 每个上屏卖点都有证据，无证据不上
- [ ] 低VOC/无异味：报告未到前只说"无刺鼻味"，不喊"零甲醛"
- [ ] 防漏/保温等宣称不混用、不夸大

## D. 结构与转化
- [ ] 前3秒出产品+痛点，无骗播无关剧情
- [ ] 税费心智：已前置"ราคารวมภาษีนำเข้า（含税到手）"或相应表达
- [ ] 视频与详情页口径一致，不各说各话
- [ ] 关键词/hashtag 用精准词（รถเก๋ง/พับได้/แข็งไม่ยุบ），非只堆大词

## E. 合规与复盘
- [ ] 无侵权素材（画面/音乐/品牌词，未用 SEAMETAL/HOTOR/NeatBox/KNODEL 等）
- [ ] 已在《案例记录》登记角度/选题/车型
- [ ] 画面清晰、字幕无错别字、时长合适
