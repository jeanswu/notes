# 《引爆流量》蒸馏（泰国电商适用版）

> 原书：杨坤龙《引爆流量：公域引流与私域裂变实战手册》，中信 2022.01，媒老板商学院。
> 性质：中国微信生态私域打法。2026-10-06 经三步法筛选——**渠道层基本不适用，底层成交心理与发售节奏可迁移**。

## 一、总闭环（直接采用）
**引流 → 成交 → 复购 → 裂变**。与我们 OPC 完全一致，是全书最该记住的骨架。
- 泰国对应：**公域=TikTok短视频/直播/搜索；私域=TikTok粉丝+未来 LINE Official Account**（LINE 是泰国的"微信"，不是微信）。
- 公域负责发现与信任，私域负责复购与裂变；不要在公域里追求一次成交，要设计"留资/沉淀"动作。

## 二、先画像、再投放（采用，已与客户经营原则并轨）
- 没有客户画像不做内容和投放。标签三维度，可直接用：
  - **属性标签**：性别/年龄/城市/车型（我们尖刀=Yaris女性）
  - **行为标签**：看过哪类视频、加购未付、互动频次
  - **交易标签**：客单价、复购次数、最近购买
- 用法：标签组合 → 分群 → 匹配不同内容/优惠；不追求标签大而全，只打高价值维度。

## 三、成交心理（采用，补情绪价值体系）
顾客购买=需求被唤醒 + 信任足够 + 此刻有行动理由。对应动作：
1. 用真实场景唤醒需求（before/after 整理对比）；
2. 用硬证据+人设建立信任（承重/急刹/防水/尺寸）；
3. 给一个"现在下单"的理由（共同券/限时，但不自杀式降价）。

## 四、一对一成交五步（迁移到客服 DM，采用）
**破冰 → 挖需求 → 给方案 → 解顾虑 → 促行动**。
- 与我们"先泄后导"结合：先共情、再问真实用途和顾虑、只推匹配的（含加价购/50#），不硬塞。
- 多给一个选项而非逼单；泰国人反感强压，"促行动"用温和的库存/时效提示。

## 五、发售节奏：售前预热—售中氛围—售后追踪（采用，用于大促/新品）
- **售前**：连续内容预热造势，筛选意向用户（点赞评论=意向信号），逐步剧透，**购买通道最后才放**。
- **售中**：制造真实从众氛围——晒单/订单雨、真实剩余库存、温和倒计时（时间或数量二选一）。
- **售后**：一对一追踪使用情况，引导好评、复购、转介绍（=裂变入口）。
- 迁移场景：11.11/12.12 新品上架、未来 TikTok直播 或 LINE 群发售。**所有节奏需泰国本地化，氛围强度调低**。

## 六、明确不采用（渠道/手段冲突）
- **微信全家桶**（公众号/小程序/企业微信/朋友圈/微信群）：泰国不用，禁止平移；私域改走 LINE OA，且待跑通后再建。
- **百度竞价/付费信息流**：我们冷启动零付费，不做。
- **100+矩阵号霸屏、工具混剪千条**：违背"垂直精品+真人实拍证据"，不做。
- **"自己评论自己"、小号造势**：属虚假互动，踩不刷单红线，不做。
- **强逼单/高压倒计时**：与泰国佛系消费文化、平台规则及我们"真诚不操纵"冲突，弱化为温和提示。
- **快闪群清库存**：书里也强调快闪群不卖尾货；我们本就无库存，不适用。

## 七、落地提示（开店后）
- 先把标签体系和 DM 五步用起来（零成本）；
- 大促前按"售前-售中-售后"节奏排内容日历，泰国人审校；
- 日出稳定后再评估 LINE OA 私域与群发售，不提前投入。
