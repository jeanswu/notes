# 单人跨境电商经营控制塔：以订单利润为核心、履约为边界、9610 合规为底座

> 2026-10-26 定稿。这份笔记经过三稿迭代：系统蓝图（v1）→ 加厚版经营方案（v2）→ 评审修订意见（v3），并对其中关键合规与税务事实做了公开来源核实。
> 适用场景：单人（或极小团队）运营、无海外库存、跨境直邮（9610）、平台电商（TikTok Shop 等）起步阶段。

---

## 0. 一句话结论

系统不是起点，**一笔真实订单跑通、账算得清、现金不断**才是起点。
售前用利润、产能和现金决定"能卖多少"；售后用订单、包裹、申报和结算事件保证"每单可追踪"；订单成熟后用实际利润决定"继续放量、调整包装价格，还是立即停售"。

北极星指标不是 GMV，而是：

```
有效经营结果 = 成熟订单实际贡献利润 − 未计入订单的异常处理成本 − 资金占用成本
```

"成熟订单" = 已结算 **且** 已过售后观察期。三条硬约束不可突破：

1. 合规不可突破；
2. 平台履约承诺不可突破；
3. 单笔订单最低贡献利润不可突破。

系统每天只需要回答五个问题：

- 今天最多能安全卖多少单？
- 哪些订单实际能赚钱？
- 哪些订单可能无法按时履约？
- 哪些内容、达人和价格组合带来了真实利润？
- 哪些异常需要我亲自处理？

## 1. 利润模型：三本账，不重复扣减

### 1.1 三本账分开

| 账目 | 用途 | 售后成本处理 |
|---|---|---|
| 售前保底利润 | 定价、优惠、投放、上架决策 | 使用风险准备金（事前估算） |
| 订单预计利润 | 履约过程中的动态预测 | 使用最新预计损失 |
| 订单实际利润 | 结算与经营复盘 | 只扣真实退款/赔偿/退货损失，**不再扣准备金** |

公式：

```
订单预计贡献利润 = 预计净收入 − 预计可变成本 − 售后风险准备金
订单实际贡献利润 = 实际净收入 − 采购及履约实际成本 − 平台及获客实际费用 − 实际售后损失 − 实际汇兑损失
```

要点：

- 准备金只在"预计账"出现一次，实际损失只在"实际账"出现一次，广告分摊、达人佣金同理，**每个科目只扣一次**。
- "预计净收入"必须事先界定是否包含买家运费、平台补贴、平台代收税费。
- **买家承担、平台代收的进口关税和 VAT，不是卖家成本，也不是卖家收入**；但要单独记录它对转化率、拒收率、退款率的影响。
- "已签收"不是利润确认点：签收后仍可能退款、退货、拒付、平台赔付调整。过程指标看"已签收订单预计贡献利润"，结果指标看"成熟订单实际贡献利润"；未成熟 cohort 只进预测看板。

### 1.2 订单级全口径成本清单

```
到岸贡献利润 = 售价
  − 商品采购成本
  − 国内段运费
  − 集运/验货/操作费
  − 9610 申报及口岸费用
  − 国际干线费用（按计费重 = max(实重, 体积重)）
  − 清关、关税、VAT 及相关服务费（注意承担方，见第 5 节）
  − 末端派送费
  − 平台佣金及支付费用
  − 达人佣金
  − 广告分摊
  − 退款/退货/丢件/破损准备金
  − 汇兑及结算损失
```

大体积轻货（如车载布艺收纳箱）的最大杀伤往往不是采购价，而是**体积重**。必须用供应商实际出货包装（不是商品展开尺寸）计算；压缩折叠方式和装箱方案，可能比压低一两元采购价更影响利润。体积重导致利润盖不住获客成本时，先改包装、换尺寸、换 SKU，而不是转海外备货。

## 2. 刹车前移：售前控制成交，售后只管履约

付款后才发现不赚钱，不能零成本取消——取消订单还会损害店铺履约表现。因此拆成两道控制：

**售前控制（决定是否允许成交）**——在上架、改价、发券、开投放前执行：

- 最低售价 / 最低贡献利润校验；
- 可售额度与日订单上限校验；
- 线路、包装、税费、承诺时效校验；
- 优惠、达人佣金、广告成本联动校验。

**售后控制（决定如何履约）**——订单付款后只做：

- 数据完整性检查；
- 供应与履约风险识别；
- 成本重估与异常预警；
- 必要时人工处理。

**铁律：不得仅因实际利润转负而自动取消已支付订单。** 某类订单持续亏损，应改后续售价、优惠、线路或停售，不把损失转嫁给已成交买家。

### 2.1 可售额度 ATP（含时间维度）

```
ATP = 国内仓已验收可用库存 + 已锁定供应商配额 − 已占用数量 − 安全缓冲
```

"已锁定供应商配额"必须具备可执行条件：锁定数量与 SKU 版本、锁定开始与失效时间、最迟发货时间、违约/缺货处理方式、最近一次供应商确认时间。**超过有效期的配额自动归零；供应商未稳定前，未锁定的工厂库存按 0 计。** 1688 页面库存 ≠ 店铺可售库存。

### 2.2 两个独立刹车

```
日安全订单上限 = min(
  供应商可履约量,
  国内仓处理量,
  申报处理量,
  国际线路运力,
  售后处理能力,
  现金可支持的订单量
) × 安全系数
```

- **数量刹车**：防供应、仓库、线路超载；
- **现金刹车**：防未来若干天刚性支出超过可用现金与确定回款。采购和国内/国际物流往往先付款、平台货款后结算——即使每单盈利，爆单也会造成现金断裂。

自动限售/停售触发条件：工厂库存无法再次确认；国内物流单号超时未回传；集运仓积压超限；线路暂停或时效严重恶化；实际贡献利润跌破底线；同批次质量异常率过高。

## 3. 第 0 关与三级验收门槛

### 3.1 第 0 关：开发任何系统前，先用真实订单跑通全链

```
平台订单 → 订单/支付/物流数据匹配 → 供应商备货 → 国内集运仓收货/验货/称重
→ 9610 清单申报 → 海关放行 →（结关/汇总）→ 国际干线
→ 目的国清关及税费处理 → 末端派送 → 签收 → 结算 → 退款/退货演练
```

**工厂给出国内快递单号 ≠ 出口发货完成。** 只有集运仓收货、验货、申报放行之后，才能向消费者提供可信的国际物流状态。工厂"支持一件代发"不等于能完成跨境履约；真正需要的是工厂能稳定把合格商品送到你的国内集运节点。

第 0 关前必须书面确认：

1. 经营主体具备该平台该站点的跨境卖家资格；
2. 9610 服务商接受"一票一件"、该商品品类、该目的国线路，能出双抬头清单；
3. 平台后台认可该线路的面单、物流轨迹与时效；
4. 退件地址、弃件、退款、破损/丢件赔付责任有书面依据；
5. 9610 后端走"汇总申报"还是综试区"汇总统计"，月度清单号/回执/凭证由谁、按月提供（见第 4 节）。

### 3.2 三级验收（跑通 ≠ 可以放量）

- **A 级 · 链路连通验证（3–5 笔）**：平台认可的面单与轨迹可回传；仓库能验货并给出实际重量尺寸；9610 能申报并取得回执；目的国清关、税费承担、末端派送路径明确；退件/退款/赔付有书面依据。
- **B 级 · 数据闭环验证（约 30 笔完整签收结算）**：每笔平台结算都能拆回订单；所有实际成本有凭证；预计利润与实际利润差异可逐项解释；退款/补发/弃件进入利润账；无未解决的申报与单证问题。
- **C 级 · 有限放量验证（约 100 笔成熟订单，或若干完整结算周期）**：不只看平均利润，**低分位订单也要守住最低利润线**；供应、首扫、清关、签收时效稳定；售后损失在定价可承受范围内；爆量情景现金充足；异常数量未超过单人处理能力。

数量是起步建议，不是统计保证。30 天的合理目标是跑通"人工控制塔"，不是证明可以自动放量。

## 4. 9610 合规底座（已核实）

### 4.1 两种通关后处理方式

- **常规：清单核放、汇总申报。** 出口后于**每月 15 日前**（遇节假日顺延）将上月结关的《申报清单》按"八个同一"（同一收发货人、运输方式、生产销售单位、运抵国、出境关别、最终目的国、10 位 HS 编码、币制）归并，汇总形成出口货物报关单；未主动申请的，**每月 16 日系统自动汇总**发送至单一窗口，企业提取确认后申报。汇总报关单用于后续退税和收汇。
- **综试区简化：简化申报、清单核放、汇总统计。** 不涉及出口征税、出口退税、许可证件管理，且**单票价值在人民币 5000 元以内**的综试区零售出口，经税务和外汇部门同意后，**不再汇总生成报关单**。无进项发票时适用"无票免税"（免征出口增值税、不退税），符合条件的综试区企业所得税可按核定方式处理。清单与报关单具有同等法律效力，企业对申报真实性负责。

来源：《中国海关》2025 年第 12 期《9610 模式出口通关指南》（深圳海关）；中国贸促会贸企通《跨境电商 9610 出口操作流程》（2026-02）。

### 4.2 状态机要走完出口端全程

```
…→ 9610 已申报 → 海关已放行 → 实际离境/结关
→ 待汇总申报 → 已汇总申报 / 汇总统计 → 收汇结算核对 → 单证归档
```

必备字段：出口申报主体及服务商；申报清单号与关联订单号；申报价格、币制、汇率版本；HS 编码、申报品名及人工复核人；交易/收款/物流数据一致性状态；退单、查验、改单原因；结关日期、汇总批次、申报回执；原始订单、支付、物流、结算凭证位置。

注意：**9610 只解决中国出口端监管，不等于目的国进口清关、纳税、平台履约已合规。** 两条链路分别建状态，用包裹号关联。

### 4.3 状态机允许"分叉"，数据模型允许"多对多"

至少区分三个对象：**订单行**（哪个 SKU、多少、多少钱）、**采购单**（向谁采购、何时到仓）、**包裹**（实际装了哪些订单行、重量尺寸、申报与物流状态）。否则处理不了一单多 SKU 分包裹、多订单合并采购、部分缺货取消、换货补发、实重与申报重不符、退货弃件与平台赔付。

每个状态除"截止时间、责任方、超时动作"外，再记录：进入时间、离开时间、数据来源、原始凭证、当前责任人、下一允许状态。各节点 SLA 时钟（仓库收货、首扫、放行、清关……）分别计算。

**成本版本**：仓库实称重算利润时不得覆盖原估值——保留每次预测的输入、公式版本、时间和差异原因（采购价估错？体积重错？税费口径错？准备金不足？），用"预计与实际偏差"驱动包装和定价改进。

## 5. 目的国进口税：泰国 2026 新政（已核实）

- **2026-01-01 起，泰国取消 1500 泰铢以下低值商品免税，1 泰铢起征**；2025-12-22 泰国海关与 Lazada、Shopee、TikTok Shop、SHEIN、TEMU 五家平台签署 MOU。
- 税率：低值货物关税 **10% 起**（按 CIF），服饰鞋类最高 30%、箱包配饰 20%、电器 10%、其他按材质 10–20%；**VAT 7%**，按（CIF + 关税）计征；两税合计最低约 17.7%。**不能简化成"所有商品统一加 17%"**，品类税率不同，且海关曾讨论进一步上调。
- 征收方式：平台渠道由**平台在消费者下单结账时直接代收**，政府口径称 97% 的进口商品税款已预先计入平台展示价，买家一次付完、清关不另缴。

对卖家模型的含义：

- 平台代收模式下，关税/VAT 通常是**买家承担的"过路费"**，不进卖家贡献利润公式（实际以平台后台结算规则为准，入驻后必须用订单验证是否可能从卖家结算款扣）；
- 它真正影响的是**含税到手价的竞争力与转化率**，定价调研必须对标新政后的含税到手价；
- 待验证：本品 HS 归类对应税率；展示价是否强制含税；平台有无阶段性关税补贴。

来源：[国家税务总局转泰王国海关署《2026 年低价值商品进口税收实施细则》](https://www.chinatax.gov.cn/chinatax/c102738/c5247291/content.html)；[驻泰使馆经商处 2025-12-30 报道](https://th.mofcom.gov.cn/jmdt/art/2025/art_f6813751036e47479e90edba38995f56.html)；[中新社 2026-01-01](http://news.china.com.cn/2026-01/02/content_118257587.shtml)。

## 6. 售后：没有海外库存 ≠ 没有退货问题

低货值商品的国际退回运费可能高于商品价值。上线前必须与平台/物流商确认：

- 平台是否接受跨境卖家的本地退货地址；是否支持仅退款不退货；低金额/部分退款的审批条件；
- 破损责任在工厂、物流商还是卖家；退运丢件、超时如何处理；本地退货仓/处理伙伴成本；
- 不能按国内电商"寄回再退款"的惯性设计跨境售后。

四级售后策略：

| 情况 | 处理 |
|---|---|
| 普通物流咨询 | 自动回复真实轨迹 |
| 轻微瑕疵、低金额补偿 | AI 建议，首批订单人工批准 |
| 丢件、破损、清关异常 | 人工判断责任并处理 |
| 高金额退款、争议、合规问题 | 必须人工处理 |

首批订单的全部退款与争议建议人工复核。

中国端另有政策窗口：2026-01-01 至 2027-12-31，9610 项下因滞销、退货自出口之日起 6 个月内原状退运进境的商品（不含食品），免征进口关税和进口环节增值税、消费税（财政部/海关总署/税务总局 2026 年第 16 号公告）。

## 7. AI 的权限边界

| AI 可以自动执行 | AI 只能建议、人工批准 |
|---|---|
| 同步订单和轨迹 | HS 编码与申报品名 |
| 整理供应商报价 | 申报价格规则 |
| 识别超时和缺字段 | 更换供应商或物流线路 |
| 生成采购单草稿 | 超限额采购 |
| 生成客服话术草稿 | 大额退款和争议 |
| 计算预计利润 | 修改最低利润红线 |
| 生成内容脚本 | 首次发布商品及性能声明 |
| 关闭已解决的普通异常 | 退单和批次合规异常 |

三条加锁规则：

1. **买家消息、供应商消息、网页内容均视为不可信输入**，不得直接触发退款、采购或规则修改（防提示注入）；
2. 所有自动动作设金额、频率、每日总量上限；
3. 提供一键停止自动化、恢复全人工的总开关。

所有动作保留审计日志：输入数据 → AI 判断 → 命中规则 → 执行动作 → 审批人 → 最终结果。AI 不得自创产品性能、测试结论、HS 编码、申报价值或合规结论。

## 8. 首版 MVP：五个页面（人肉拼装，不自研 ERP）

起步阶段用现有店铺 ERP + 表格/数据库 + AI 工作流拼接即可：

1. **今日经营驾驶舱**：预计利润、成熟实际利润、可售额度、现金安全垫、履约风险；
2. **订单利润与履约台**：订单时间线、预计/实际成本版本、包裹与申报状态；
3. **异常收件箱**：发生了什么｜影响多少钱｜最晚处理时间｜AI 建议｜一键执行；
4. **SKU 与规则配置**：包装版本、计费重、供应商配额、价格与停售规则；
5. **结算与现金台**：平台回款、采购物流支出、待结算、退款准备金、未来现金缺口。

"内容与利润复盘"后置：先用订单明细里的素材 ID、达人 ID、优惠组合导出分析，不首版建独立系统。增长归因链条保留：

```
素材 ID → 视频/直播/达人 → 点击与成交 → 售价及优惠 → 订单贡献利润
→ 退款与签收 → 实际回收利润
```

高转化但高退款的内容要检查是否过度承诺；"有 GMV、没利润"的投放组合应暂停。

## 9. 30 天落地顺序

- **第 1 周 · 验证链路**：完成真实测试订单（A 级），确认店铺资格、物流、9610、目的国税费与退货口径；
- **第 2 周 · 人工控制塔**：SKU 数字护照（合规卡）、订单状态机、利润三本账、异常清单；全人工操作，记录每段真实耗时与成本；
- **第 3 周 · 接入数据**：逐步连接平台订单、采购、仓库、物流、结算数据，让系统自动发现异常；
- **第 4 周 · 有限自动化**：只开放三类自动动作——超时提醒与异常分类；外语客服及内容草稿；明确规则内的限售/停售与采购建议。

连续跑通一批完整签收、结算订单后（B 级），再考虑国内仓少量安全库存与更深自动化；利润、签收率或时效不成立时，优先调包装、售价、线路，而非转为海外备货。

启用自研系统的信号：日单稳定 ≥ 20；人肉台账每天超过 30 分钟；出现多个 SKU、多仓、多线路。

## 10. 七阶段晋级路线（终版）：1 万元预算怎么花

> 本节经过两版路线方案对比合并：八阶段版（预算闭合细、红线全）与七阶段版（骨架干净、经营指标细、自动化分级）。终版取后者结构 + 前者风控。
> 编号 0–6：**0–3 由初始 10,000 元支持；进入第 4 阶段后只能靠真实经营回款和已实现利润扩规模**，不能假设 1 万元能覆盖最终形态。按验收门槛晋级，不按日历晋级；每阶段必须**全部**满足关键门槛，不能用平均值掩盖亏损订单。

### 10.1 自动化等级

- **L0**：人工处理，表格记录；
- **L1**：自动导入数据、计算和报警，人做决定；
- **L2**：售前规则门禁、审批流、成本和现金账本；
- **L3**：Agent 在金额、频率和权限范围内执行低风险动作；
- **L4**：闭环优化和受限自治，人工只处理策略、异常与高风险审批。

### 10.2 资金结构（1 万元闭合）

- 独立风险准备金（不采购、不投流、不动用）+ 经营验证资金 = 10,000 元；风险准备金建议不低于 3,400 元；
- 阶段 0/1/2/3 的**累计**支出建议上限：300 → 2,000 → 4,000 → 6,600 元（经营验证部分）；
- 项目被证伪时，最大净损失 ≈ 阶段 0–2 的沉没成本（样品 + 3–5 笔测试单），周转金随库存与回款大部分可回收；
- 阶段 4 起零新增预算，只使用经营回款；系统投入不超过近 3 个月已实现贡献利润的 20%；现金不足时减少订单，不借款、不压货、不拿亏损换 GMV。

### 10.3 统一口径

沿用第 1 节与 3.2 节定义：成熟订单（已签收+已结算+过售后期再观察 7 天）；实际贡献利润率 = 实际贡献利润 ÷ 卖家实际净收入；负利润订单占比；标准订单；现金安全垫 = 未来 N 天刚性支出 + 待退款 + 售后准备金（N 随阶段从 14/21 天逐步提高到 60 天）；日安全订单上限 = 可周转现金 ÷（单均垫付 × 占用天数）× 70%；样本 <30 单不看百分比、看证据完整性。所有利润率均指**全口径到岸贡献利润率**（扣完采购、头程、9610、国际运费按计费重、清关末端、平台佣金、支付费、达人佣金、售后准备金、汇损；平台代收、买家承担的进口税不计入收入也不计入成本）。

### 10.5 售前利润三级门（阶段 1，全口径到岸贡献利润率）

同一份成本表，按三种获客情景各算一次，同时成立才放行上架：

1. **零付费自然流情景**：≥15%（留足后续阶段损耗缓冲）；
2. **达人佣金情景**：按实际可承受纯佣（示例 8%）扣减后 ≥8%；
3. **最差情景**：保守线路价 + 较高退货假设 + 四项压测叠加后 ≥0（不亏现金）。

> 说明：曾有方案提出"广告前贡献利润 ≥35%、广告后 ≥15%"。35% 往往是未扣国际运费/平台费的窄口径毛利，与全口径到岸利润不可混用；而付费投流并非必选项。统一改用上表全口径口径，第二级换成达人佣金情景。若坚持付费投放，则把第二级替换为目标 CAC 情景并同样要求 ≥8–10%。

### 10.6 两条防过度工程规则

- 只有同一个人工操作重复 **20–30 次**之后，才值得把它自动化；
- 阶段 4 之前不建"系统"，轻量案卷四张表足够：订单/包裹/履约、SKU/供应商、利润三本账与平台结算、现金与异常日志。

### 10.7 降级红线与总止损

- 任一阶段门指标连续两周失败：暂停放量，优先修复供应链与单位经济，不继续增加自动化；
- 立即触发（不等周期）：未解决合规问题停新单；连续 7 天新单预计利润为负停该价格/素材/优惠组合；现金低于安全垫停投放与非必要采购；首扫及时率 <95% 或同线路连续重大超时限售；出现 1 次未授权退款/采购/改价/申报关闭对应自动化；无法解释的结算差异或重复入账暂停自动化、恢复人工；连续 3 天异常当日清不完，下调日订单上限；
- **总止损：阶段 0–2 沉没成本触及 4,000 元、仍未拿到 ≥3 笔签收结算且链路存在重大异常，停下复盘，不追加预算。**

### 10.8 永久人工事项（L4 也不放手）

HS 编码、申报品名与申报价格规则；新商品性能与测试声明；首次更换供应商、物流线路或申报模式；大额退款、争议与平台投诉；修改最低利润、现金与合规红线；进入新市场、面对新税务与新进口规则。

## 附：五稿迭代中的勘误记录

1. **模板噪音剔除**："上海海关书面确认"——若经营主体不在上海口岸，确认对象应是实际 9610 服务商与平台后台规则；"FedEx 体积重"字样——若实际走平台官方跨境物流渠道，计费重规则以该渠道为准，`max(实重, 体积重)` 原则保留。
2. **税务表述纠正**：不能写成"所有商品统一加 17%"；关税按品类 10%–30% 不等，VAT 7% 叠加在（CIF+关税）上，且平台代收模式下通常不是卖家成本。
3. **9610 后端纠正**：不是所有 9610 都要每月 15 日汇总报关单；综试区符合条件（单票 ≤5000 元、不退税、无进项票）走"汇总统计"，但凭证按月归档与收汇核对不能省。
4. **利润公式纠正**：准备金与实际售后损失不得在同一口径重复扣减；北极星指标扣的是"成熟订单"之后的真实损失。
5. **验收标准纠正**：3–5 笔真实订单只能证明"链路可能通"，不能证明供应稳定、时效稳定、利润成立，故设 A/B/C 三级门槛。
6. **路线终版合并**：八阶段版与七阶段版对比后合并为第 10 节七阶段（0–6）+ L0–L4 自动化分级；明确"1 万元只购买 0–3 阶段验证，第 4 阶段起只用经营回款"；剔除"广告前毛利 ≥35%"的窄口径门，统一为全口径到岸贡献利润三级门（自然流 ≥15%、达人佣金情景 ≥8%、最差情景不亏现金）；B 级利润门折中为整体 ≥5%、中位数 ≥10%、P10 ≥0。

## 11. 落地执行记录（2026-10-27 补，阶段 0→1 实操）

> 本节是方案进入实操后的脱敏记录，只写可复用的方法与避坑点，不含主体、价格、供应商身份等私人信息。

### 11.1 银行端：贸易外汇名录登记的真实办理情况

- **办理渠道以经办行为准，不预设"必须当场办结"**。部分网点对小微跨境电商的名录登记流程是"现场收资料 → 银行端录入数字外管平台 → 过几天电话/微信通知开通"，并不一定当场出回执。递交后主动锁定三样东西：受理回执、货物贸易外汇监测系统（企业互联网端）登录账号、初始密码（拿到后立即试登录并改密）。
- **"顺便开个外币账户"是营销动作，不是名录前置条件**。做平台代收+支付机构结汇的模式，没有 T/T 场景时可以不开外币账户、不开网银结售汇；政策门槛以后真有 T/T 业务时不变。名录登记本身不触发辅导期，辅导期从首笔实际外汇收支起算。
- **盖章的《基本存款账户信息》在开户当天就应拿到**（取消开户许可证后的账户证明，含基本存款账户编号），入驻平台和电子税务局三方协议都要填"开户行全称"，以这张单据上的名称一字不差照抄。该单据通常印有查询密码，属敏感件，不外发、不入共享文档。

### 11.2 供应商筛选：一次"资质很好但款式不对"的实证

对照第 10 节阶段 1 的闸门，真实走完一家备选厂的核验，结论很有代表性：

- **验厂资质硬，不等于有你要的货**。一家有 BSCI、欧洲商超客户、20 年以上历史的工厂，其主力品类（如脏衣篮/收纳筐）与你要的"600D 方形硬挺后备箱折叠箱"只是同属收纳大类；展会样品可能是新品或客户 ODM 款，非常年现货。
- **用 22 页产品册逐页排查 + 要商品链接双重验证**。产品册里没有目标结构（可拆卸中隔板、硬底板、35cm 档），销售发来的现货链接实际是另一个品类（圆形露营造口水桶，PEVA/PVC 内胆，无中隔无硬底板），最终销售确认"方形没有现货，只能定做"，而定制 MOQ（500 个）远超阶段 1 的验证预算。
- **处置方式**：归档为"未来自有品牌贴牌/大柜战略厂"，不断交、不定做、不索样；首发供应商不动；其余备选**按写死的启用时机（首发首单跑通后）再联系**——阶段 0 收尾期提前触达、索样、比价都属于过度准备。
- **细节红旗**：销售发来的商品链接，店铺法律主体与其名片工厂名不一致（自称两个店铺并行经营）。口头关联不能当证据；未来真合作时合同、发票、收款主体必须对准验厂资质所在的法律主体，并做股权穿透复核。

### 11.3 平台 KYC 影像材料的拍摄避坑

- 营业执照副本与正本等效，平台机审读统一社会信用代码与印章；拍前摆正、四角完整、铺满画面、无反光。
- 身份证注意两点：①手机方向传感器可能把证件照自动转横，**拍摄后在相册旋转正向、另存为新图**（编辑后的像素方向不依赖 EXIF，机审不会读横）；②卡片边缘有磕损时重拍对焦清晰、避免缺口阴影，降低"证件破损"驳回概率。
- 手持证件照请他人用**后置摄像头**拍摄、关闭镜像；人脸与证件四角、号码同时清晰，手指不遮挡信息。

### 11.4 阶段 0 检查清单（实操版）

1. 主体资格、经营范围含进出口相关条目；
2. ≥2 家 9610 服务商书面报价（计费重规则、最低收费、时效、异常赔付、清单回执与月度凭证口径）；
3. 泰国端税费承担与结算页展示方式，以下店当天实测为准；
4. 末端派送与退货方案 ≥2 种、责任书面化；
5. 银行：基本户可用、名录已登记、外币户按真实业务需要再开；
6. KYC 影像包：执照、身份证正反面、手持证件照，方向正向、清晰可辨。

> 进度状态：阶段 0 收尾（名录在途、平台入驻递交在即），阶段 1 供应商开发按闸门推进，首发 SKU 不更换。
