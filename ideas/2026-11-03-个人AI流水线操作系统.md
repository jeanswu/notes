# 个人AI流水线操作系统 v1.0

**一句话蒸馏**：性格短板修不好，只能被绕过——把每条短板写死成系统里"无法犯错"的闸口，人只做拍板，智能体做执行，流水线做纪律。

---

## 0. 第一性原理推导：为什么系统必须长这样

### 0.1 不可谈判的物理约束（公理，不是观点）

| 编号 | 物理事实 | 推论 |
|---|---|---|
| A1 | 只有一个人，每天可用精力 ≈4-6 小时 | 系统必须为"最低精力输入"设计，默认值=不做 |
| A2 | 资金承受力偏保守，需严格止损 | 每条战线必须有自动止损器，靠人自觉=没有止损 |
| A3 | 43 岁，意志力是消耗品，20 年职场证明"靠自律"失败 | 所有纪律必须外化为机器执行，不允许"我尽量" |
| A4 | 不露脸、不会泰语 | IP 走幕后型方法论路线；泰语面 100% 由 AI 承担，不设人工备份 |
| A5 | 单人 = 无同事监督、无截止时间、无外部反馈 | 系统必须人工制造：截止、评分、羞耻感 |

### 0.2 第一性命题

> **人的短板是物理常数，不是待修复的 bug。任何依赖"更好的自己"的方案，在第一性原理上就不成立。**

所以设计目标不是"让我更自律"，而是：**在我最懒、最逃避、最想开新线的状态下，系统仍然运转**。

### 0.3 马斯克五步算法的应用顺序（顺序即方法论）

```
① 质疑每条要求 → ② 删除 → ③ 简化 → ④ 加速循环 → ⑤ 自动化
```

- **① 质疑要求**：每条"我要做 X"必须能追溯到唯一主线（第一笔人民币回款）。追溯不到 = 要求是假要求，删。
- **② 删除**：先删战场（WIP=1），再删动作（打磨类），再删系统（未跑通前的一切自动化）。删到疼为止——删完后如果不需要把 10% 加回来，说明删得不够。
- **③ 简化**：留下的每个动作必须是"今天能执行、48 小时内出真实反馈"的原子动作。
- **④ 加速循环**：把"动作→真实反馈"的周期从周压到天。迭代速度是唯一可自我强化的变量。
- **⑤ 自动化（永远最后）**：自动化错误的流程，只会让错误提速。流水线只在全链路手工跑通至少一遍之后才有资格存在。

> 关键提醒：第五步的排序意味着——**"最好是能形成 AI 流水线自动化"这个愿望，本身就是系统要防的短板之一**。自动化是跑通后的红利，不是起跑姿势。

## 1. 短板 → 防呆闸口 → 智能体映射表

每条短板配一个机器闸口。人不负责克制，闸口负责拒绝。

| # | 短板（已验证的行为模式） | 防呆闸口（机器规则） | 承担者 |
|---|---|---|---|
| 1 | **研究避难**：研究/学习/打磨提示词是舒适区，零风险、有掌控感、永不被市场打脸 | 守门人：任何议题必须回答"由哪条真实市场反馈驱动"，答不上即打回 | 守门人智能体（已上线） |
| 2 | **兴趣分散**：新点子多，容易开第二战场 | 仲裁官：WIP=1，新想法强制进停车场，超 14 天未碰自动标红待删 | 仲裁官智能体（已上线） |
| 3 | **止损拖延**：沉默成本+乐观偏差，该砍不砍 | 记分牌：每周固定判定 加码/止损/打回，规则写死，不允许"再看看" | 记分牌智能体（已上线） |
| 4 | **无外部 deadline**：单人无人催 | 每日唯一动作：昨天没更新，系统红字追问"诚实面对为什么" | 工作台（已上线） |
| 5 | **决策瘫痪**：选择多了就不动 | 拍板队列：系统每周最多向你提交 3 个决策，每个必须带"推荐答案+依据"，你只回 1/2/3 | 包工头智能体（M1 上线） |
| 6 | **完美主义**：交付前无限抛光 | 发布闸：满足验收清单即强制发布，"再改一版"需要守门人书面批准 | 发布闸（M1 上线） |
| 7 | **语言短板**：泰语面如果靠人，全流程卡住 | 泰语零人工：内容、客服、售后 100% AI，人工只做抽检 10% | 翻译/客服智能体（M1 上线） |

## 2. 流水线总图（目标态）

```
                        ┌─────────────────────────────┐
                        │  你（只做两件事：定唯一动作、 │
                        │      对拍板队列回 1/2/3）      │
                        └──────┬───────────────▲──────┘
                               │ 输入           │ 上报
                    ┌──────────▼───────────────┴──────────┐
                    │        AI 包工头（总控/监工）          │
                    │  派单 · 查进度 · 质检 · 只带方案请示   │
                    └──────────┬───────────────┬──────────┘
              ┌────────────────┼───────────────┼─────────────┐
        ┌─────▼─────┐   ┌──────▼──────┐  ┌─────▼─────┐  ┌────▼─────┐
        │ 侦察兵     │   │ 内容工厂     │  │ 履约员     │  │ 数据员    │
        │ 市场扫描   │   │ 泰语内容生成 │  │ 客服/售后  │  │ 漏斗采集  │
        │ 竞品逆向   │   │ 发布/分发    │  │ 订单跟进   │  │ 周报生成  │
        └─────┬─────┘   └──────┬──────┘  └─────┬─────┘  └────┬─────┘
              └────────────────┴───────┬───────┴─────────────┘
                                       │ 所有产出
                            ┌──────────▼──────────┐
                            │  三闸门（质量与纪律）  │
                            │ 守门人/仲裁官/记分牌  │
                            └──────────┬──────────┘
                                       │ 判定+经验
                            ┌──────────▼──────────┐
                            │  notes 仓库（第二大脑）│
                            │  回流 → 成为下周上下文 │
                            └─────────────────────┘
```

**单向闭环**：你 → 包工头 → 执行智能体 → 闸门 → 沉淀 → 喂回给你。任何一环想跳过闸门直接到你面前，包工头负责拦。

## 3. 自动化路线图（M0 → M1 → M2）

自动化分三级解锁，**每一级的解锁条件都是上一级的真实数字**，不是心情。

### M0 · 现在（手工核 + 已上线闸门）
- 已有：三闸门、今日唯一动作、主线卡（第一单全链路）、链路漏斗、停车场
- 你每周日手工填 4 个数字（约 10 分钟）——**这是故意的**，给不存在的流水线抛光是第 1 号短板的变种
- 唯一主线：触达 → 意向 → 成交 → 交付 → 回款进人民币公司账户
- 解锁 M1 的条件：**第一笔人民币回款到账**

### M1 · 首单后（包工头 + 执行智能体矩阵）
- 用首单复盘的"卡点清单"作为智能体的需求文档——**卡点即需求**，不为想象中的效率搭智能体
- 上线顺序按卡点严重度：泰语内容工厂 → 履约客服 → 数据员 → 侦察兵
- 包工头上岗第一天只做三件事：派单、查 deadline、把需要你决策的事打包成拍板队列（≤3 个/周，每个附推荐方案）
- Evals 先行：每个智能体上岗前，先用真实业务数据建评测集（你的老规矩：先有尺子，再放模型）
- 解锁 M2 的条件：连续 4 周记分牌绿 + 包工头误判率 < 20%

### M2 · 流水线态（全自动数据回流）
- 后台数据自动进漏斗，记分牌自动生成，周日你只做一件事：看判定卡片，回"同意/不同意"
- 包工头具备逆向工程能力：平台规则变化、工作流低效时，自动提交修复方案（方案仍需你拍板，合规红线永远人工确认）
- 每周自动产出"本周经验"笔记，push 进 notes 仓库，回流为所有智能体的上下文

## 5. 每周运行节奏（机器的日历，不是你的）

| 时间 | 机器做什么 | 你做什么 |
|---|---|---|
| 每天 08:00 | 工作台推送"今日唯一动作" | 写下今天能产生真实反馈的一件事（2 分钟） |
| 每天 22:00 | 检查动作是否更新；未更新 → 红字追问 | 诚实回答（30 秒） |
| 周日 20:00 | 记分牌汇总本周数字，出判定卡 | 填 4 个数字，看判定，拍板下周加码/止损（15 分钟） |
| 任意时刻 | 新想法进来 → 仲裁官直接收进停车场 | 什么都不做 |
| 每周 | 包工头（M1 后）提交拍板队列 ≤3 项 | 每项回 1/2/3 |

**你的总时间预算：每天 ≤30 分钟经营动作 + 周日 15 分钟。** 超出的部分，要么交给智能体，要么删除。

## 6. 推翻的旧认知

1. ~~"我要先提升自己，才能做成事"~~ → 短板是常数，绕过它的系统才是变量。
2. ~~"自动化越早越好，AI 流水线是核心竞争力"~~ → 自动化是五步算法的第 5 步。未跑通就自动化 = 给避难所装电梯。
3. ~~"管理靠自觉和复盘"~~ → 管理靠闸口。复盘只在机器把数字摆在你面前之后发生。
4. ~~"超级 IP 需要露脸、需要大投入"~~ → 幕后型方法论 IP（公开 AI 创业实录）同样成立，且与 A4 约束兼容。

## 7. 怎么用

1. 本周：什么都不用建。打开工作台，写今天的唯一动作。系统是 M0，已就绪。
2. 每次冒出"我可以做个工具/系统/自动化"的念头 → 提交三闸门，预期被打回，这是设计如此。
3. 第一笔回款到账当天 → 回来启动 M1：用首单复盘卡点清单派生第一个执行智能体。
4. 本文档作为 notes 仓库 `ideas/` 下的执行层文件，与总纲互链，每完成一次阶段解锁更新 `updated` 字段。
