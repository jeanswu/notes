## 0. 一句话灵魂
**想清楚（先删不该做的 → 用硬事实立住 → 算清赔率和死法）→ 小验（预设怎么算错、前提倒即停）→ 跑通才放大/标准化。**
顺序不能反：先问"该不该做"，再问"怎么做"；验证之前不优化、不放大、不自动化。

## 1. 五环节「删—立—算—验—复」（电商版）

### ① 删 —— 先问该不该做
- 这件事现在不做会怎样？是"不做会损失"，还是"手痒想做"？
- 删掉一切"别人都在做所以我也做"：跟卖、铺矩阵、买流量、上一堆品、蹭每个热点。
- 给重大决策设硬名额（20格考勤卡）：全年重决策≤5个（首店、首品、首次放大、第二品、第二站点），名额没用完不丢人。
- 芒格："不为行动而行动"+"三年不到一次重大决定"（蓝筹印花）。

### ② 立 —— 拆到硬事实，从地基往上推
- 不靠类比、不靠"某某店这么做成了"。硬约束公式：
  **一笔成交 = 真实需求 × 可信内容 ×（售价 − 全成本 > 0）**
- 例：全成本后仅[见本地台账]%毛利 → 付费买量从根上不成立（不是"广告贵"），达人佣金>8%即亏。
- 先锁"无需费神的大是大非"（合法/稳当/复利三原则），脑力只留给真变量。
- 只做能力圈内的；"太难理解"（纯贸易/IP侵权/看不懂的高科技玩法）一律归"太难"不碰。

**横向复查·多元格栅（别拿一把锤子看问题）：** 纵向拆完，强制换 2–3 个学科视角再验一遍：
- 数学：期望值（算多次重复，不算单次赌赢）、毛利结构、复利
- 工程：安全边际（安全垫≥3000/不押库存）、断点、冗余
- 经济学：机会成本（这笔钱/这个时段最好的别的用法）、激励、规模效应
- 心理学：消费者真实动机（情绪价值常是真需求的一部分）+ 自己此刻的偏差
- 生物学：生态位（尖刀＝Yaris女性小车，占住再扩）、适者生存（算法一变寄生玩法先死）
- 系统：正/负反馈、临界质量（账号权重引爆点）、自催化（内容→粉丝→信任→复购）

### ③ 算 —— 赔率 ＋ 列死法 ＋ 看清激励
- **赔率两问**：赢面多大？赢了赚多少 vs 输了亏多少（钱/时间/信用）？输了我能活下来吗？不划算再热闹也放弃。
- **逆向失败清单**：不问"怎么爆/怎么赢"，先列"**怎样保证这个品/这条视频必死**"，逐条排除：
  - 品：IP侵权、易碎物流、售后失控、库存押钱、汇率/税/佣金剧变、纯贸易低价内卷
  - 视频：前3秒没钩子、像广告、泰语机翻味、夸大承诺被限流、盗图撞原创度、发布当天改账号资料
- **激励超级权力**："告诉我激励，我告诉你结果。"判断供应商/达人/货代/平台/代运营，先看他靠什么赚钱，他的建议天然朝他利益偏（达人要高佣爆品≠你能给8%；代运营要你多投流≠你账算得过来）。

### ④ 验 —— 小步先验，预设推翻条件
- 最小验证：先验产品力 → 测素材 → 正反馈再放大；零付费、纯佣≤8%。
- **每个决定必须写得出"什么证据出现就证明我错了"**；写不出＝这是信仰不是判断。
- 反确认：主动去找能杀死自己观点的证据（学达尔文优先看反面）。
- **二阶思维（and then what?）**：每个动作追问后果的后果。
  - 降价拉销量（一阶）→ 平台价格锚定＋利润垫打没（二阶）→ 养出只认低价的用户、品牌立不住（三阶）。所以大促不自降、只用共同券。
- **Lollapalooza 共振诊断**：多因素同向叠加＝非线性核爆。
  - 恶性：高退货＋盗图限流＋无品牌＋差评螺旋向下 → 单点修补无用，要么同时拆掉那几股力，要么整体止损，绝不"再优化一下"。
  - 正向（要主动组织）：产品力（真需求/硬挺不塌）× 内容力（本土话术/原创实拍）× 情绪价值（精致疗愈）× 信任（RIABA品牌/真人/合规）同向，才会起量；死磕单个钩子造不出共振。

### ⑤ 复 —— 跑通才标准化/自动化（永远最后）
- 没验证的流程绝不提前做精美SOP/工具/自动化＝给垃圾抛光，禁止。
- 跑通的动作沉淀成可复利资产：原创内容、本土话术库、品牌RIABA、供应链关系、可复用SOP；少做一次性消耗（买一次量、蹭一次热点、打一次折）。
- 好生意一个接一个抛"容易的决定"，烂生意逼你反复痛苦决定——选品时预判它未来一年是省心出单还是持续扯皮退货。
- 只和高品位的人合作（不要和猪摔跤）；SOP越短越好；说话算数＝一人公司唯一的复利资产。

## 2. 电商兵器谱：什么场景抽哪把

| 场景 | 先用的兵器 |
|---|---|
| 想上新品/新渠道/新玩法 | 删（名额）＋能力圈＋安全边际＋逆向失败清单 |
| 心里痒、怕错过、同行都在做 | 先审自己：社会认同/FOMO |
| 判供应商/达人/货代/平台建议 | 激励引起的偏见（他靠什么赚钱） |
| 拆"为什么卖不动" | 5Why纵向＋事实校验＋二阶后果 |
| 一堆原因缠着、怎么补都没用 | Lollapalooza恶性共振→同时拆力或止损 |
| 想让生意/内容真正起量 | Lollapalooza正向版（组织多因素同向） |
| 纠结降价/投流/打折 | 二阶思维＋这是资产还是消耗 |
| 机会多、都想做 | 机会成本＋少而重＋打穿一个再复制 |
| 发布/投钱/签约前 | 检查清单逐条过（泰审7红线/四方验证/开店核验） |
| 做着做着怀疑方向错了 | 硬前提止损＋不护沉没成本＋干脆认错 |

## 3. 一页决策检查清单（重大决策逐条过，留痕）

**删**
- [ ] 现在不做会怎样？是真损失还是手痒？今年名额还剩几个？
**立**
- [ ] 依据是硬事实/数据，还是"别人做成了"的类比？
- [ ] 在能力圈内吗？"太难理解"的部分是不是在硬赌？
- [ ] 换过≥2个学科视角横向复查了吗？是不是正拿一把锤子看问题？
**算**
- [ ] 赢面/赢赚 vs 输率/亏多少（钱时间信用）？输了能活吗？
- [ ] "怎样保证必败"清单写了吗？每条死法有对策吗？
- [ ] 相关各方激励是什么？谁赚钱、谁担风险？
**验**
- [ ] 最小验证是什么？哪个证据出现就证明我错、必须止损？
- [ ] 二阶/三阶后果想过吗？这是资产动作还是一次性消耗？
- [ ] 是不是没验证就忍不住在优化/美化/自动化？（是→打回）
**复**
- [ ] 跑通后是持续送"容易决定"还是持续制造"痛苦决定"？
- [ ] 哪些部分能删掉而不影响结果？能不能更简单？

## 4. 三条不可违背的红线（一票否决，不算赔率）
1. 合法：照章纳税、9610首单用[我方主体]主体、不侵权、不刷单。
2. 稳当：不押库存、不上亏损链接、安全垫≥3000、花钱/铺新线走路障模式。
3. 复利：不买流量、不靠高佣催熟；利润>销量，打穿再复制。
**外部硬前提失效（市场准入/合规通道/账成立）任一被推翻 → 立即停止运营，不做任何优化挽救**（见根本解框架第58行起）。

## 5. 芒格给电商的6个真实参照
1. 喜诗糖果：合理价买好货 > 便宜捡烂货 → 选好品不选最烂最便宜的。
2. 不要和猪摔跤 → 供应商货代起点选高层次的。
3. 努力不变蠢（第14章原话）→ 先建避免愚蠢的免疫系统。
4. LTCM长期资本：智商160的人死于高杠杆＋过度自信 → 不重仓看不懂的、留安全边际。
5. 极简主义＋放手管理（第15章）→ 生意和SOP做减法、少折腾。
6. 遭遇噩耗从不抱怨（第13章）＋降低目标（第21章）→ 数据起伏不被自怜拖垮，理性认错。
