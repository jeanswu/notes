# 泰国广告营销合规清单（2026-09-21核实）

> 用途：每条泰语视频/详情页/标题/达人话术上线前对照。监管：消费者保护委员会广告委员会（OCPB）。
> 法律：《消费者保护法》B.E.2522 (1979) 第22条；广告委员会2022年《难证实广告陈述使用指引+证实指引》（2023-01-13政府公报、次日生效，现行）。
> 注意：泰国法对"广告"定义极宽——**线上广告、电商详情页、直播、达人带货视频、私信推销全部适用**。

## 一、禁用表述（无充分证据一律不写，泰语同理）

**1. 绝对化/最高级**
- 最：最好/最便宜/最大/最结实（ดีที่สุด / ถูกที่สุด / ใหญ่ที่สุด / ทนทานที่สุด）
- 第一 / No.1 / 销量第一（อันดับ 1）
- 唯一 / 仅此一家 / 泰国唯一 / 仅此一次（เดียว / เดียวในประเทศไทย）
- 绝无仅有 / 顶级 / 王牌 / 冠军之选
- ❌ "全网最便宜"（除非有明确范围+时间+可靠市场调研，并注明出处）

**2. 比较与数据**
- 指名/暗指竞品的比较（"比别家能装/更结实"）须有可靠证据，建议不做
- 引用调研/统计/检测/销量排名：须有机构名、内容、范围口径，且发布时就持有证据（不是被查再补）；被要求举证须15天内提交

**3. 保证与效果**
- "安全无忧""保证满意""无效退款""100%""立竿见影/立即见效""7天见效"——无条件保证禁；要写须附准确条件
- 免责甩锅条款："保留不经通知变更价格/条件权利""图片仅供参考以实物为准"等不利消费者表述禁

**4. 语言与事实一致**
- 广告关键信息（数量/尺寸/容量/材质/成分）须与实际一致；用外文须附泰语译文
- 引用检测/实验须明示机构名称与实验内容

**5. 文化信仰**
- 不诉诸迷信/法事/个人信仰（增魅力、招姻缘、改运等），不针对情绪脆弱群体

## 二、处罚
- 罚款5,000–100,000泰铢，可并处≤6个月监禁；严重≤1年
- 行政命令停播/纠正；民事赔偿；屡犯可吊销执照
- 调查期间可被临时暂停广告

## 三、我们35#的安全写法（对照执行）
✅ 讲具体场景与感受：后备箱不再乱、急刹东西不飞、一提就走、折叠不占地、装得下XX
✅ 客观可自证的描述：36L容量、600D牛津布、约0.96kg、可折叠
✅ 卖点须有据：承重不虚标具体磅数；"无异味"先拿低VOC检测再用（见本地化手册禁漂绿）
✅ 话术只用泰国TOP3店铺验证过的表达，不自己造夸张口号
❌ 不写任何"最/第一/唯一/全网最/100%/保证"；不指名比较竞品
