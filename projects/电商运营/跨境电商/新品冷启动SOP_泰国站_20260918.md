# 新品冷启动SOP（泰国TikTok Shop·35#折叠箱首发）

> 建档 2026-09-18。方法论来源：电商运营猫《给你一个新品，怎么把它推成爆款？》7步框架，主人指示吸收整合。
> 与本项目其他文件的关系：本SOP是执行节奏的总串场——
> 「能不能推」看《单件盈亏模型_v1》；「卖给谁/竞品/价格带」看《泰国市场调研》；「卖点证据」看《痛点库》；「怎么说」看《泰马本地化手册》+《泰国本土话术库》。
> 最高原则一票否决：合法、稳当（不上亏损链接、不亏本冲量）、循环复利。

## 总纲：三段论

**先验证这个品有真实成交能力 → 有正反馈才放大 → 放量前确认后端接得住。**
运营不是把每个品都推成爆款，而是尽早识别哪个品值得继续投入。任何阶段"每卖一单都在亏"，立即停，这种爆没有经营价值。

## 第1步 判断值不值得推（我们已完成 ✅）

文章标准：市场需求/同质化/全成本利润——**"如果只有不投流时才有利润，这个品很难进入放量阶段"**。

我们的答卷：
- 需求：UN Comtrade对泰出口量+20.7%、14家在架厂、20个竞品四段价格带、社媒痛点四语种高频——四方验证通过。
- 差异化：公模白牌同质化高，但痛点TOP5（软塌/滑动/异味/尺寸/缝线）给出了可证明的改进点（全侧壁2.5mm插板、加长防滑、低VOC、36L轿车精准适配）。
- 全成本：499฿自然流毛利17.7%（单件+¥[见台账]）；**达人佣金≥10%或叠加付费广告即亏**。

⚠️ **必须正视的结构性矛盾**：按文章的付费放量逻辑，我们这个品"只有不投流才有利润"，过不了传统放量关。所以我们从第一天起走的就不是"广告催熟"路线，**放大杠杆替换为**：
1. 验证过的内容结构批量复制（内容是资产，边际成本趋零）；
2. 自然推荐+搜索流量随内容沉淀增长；
3. 达人只接**佣金≤8%**的纯佣合作（499+8%时净利约+¥[见台账]/单，不亏）；
4. 大促用平台共同出资券，卖家让价≤5%（到手≥474฿），永不自降399。
代价：起量比广告打法慢；收益：每单有利润、不依赖租金、符合复利原则。**慢就是快。**

## 第2步 定位：一个人群×一个场景×可证明的卖点（我们已完成 ✅，话术待采集）

- **核心人群**：泰国轿车（รถเก๋ง）车主——Vios/Yaris/City/HR-V/Revo保有量大的家用车人群；避开皮卡和摩托歧义词。
- **主场景**：后备箱一箱整理，急刹不滑不乱（副场景：凉季露营、Songkran湿物分隔、12月送礼）。
- **主卖点只打一个，其余做支撑**："แข็งไม่ยุบ（硬挺不塌）"——2.5mm全侧壁插板，对应全市场第一高频差评。
- 每个卖点必须有证据，无证据不上主图：

| 卖点 | 证据形式（素材要求） |
|---|---|
| 不塌 | 徒手压箱壁对比公模弯折；插板插拔特写；坐人/放重物 |
| 刹车不滑 | 行车急刹实拍（魔术贴+硅胶钉+绑带三件套特写，泰文ไม่ลื่นขณะเบรก） |
| 无异味 | 低VOC检测报告截图+开箱近闻；ไร้กลิ่น标（报告未到前不喊"零甲醛"，只说"无刺鼻味"） |
| 轿车适配 | Vios/City等车型后备箱实拍对照图+尺寸标注 |
| 耐造防泼水 | 600D微距+泼水测试 |

- 文案表达只从《泰国本土话术库》TOP3店铺/爆款原句中取形容和比喻，不自造、不中译泰。
- 禁忌按《泰马本地化手册》自检（无脚踩演示、无摸头、无佛像/王室元素）。

## 第3步 素材先证明有人点击（待办：开店后首批素材）

- **先测三组角度，不测美丑**：
  - A组 产品细节：插板/600D/拉链承重（工厂感、硬核）
  - B组 真实场景：轿车后备箱整理前后对比、露营装载
  - C组 直击问题：公模箱塌了/刹车东西飞出来的"翻车"开场
- **单变量纪律**：价格、标题、封面、人群不同时换。一轮只动一个变量，否则数据好了也不知道为什么。
- 判读方法（文章原话：结合相近流量条件持续观察，不看单条偶然数据）：
  - 点击好、停留/加购低 → 封面承诺过度，详情没接住 → 改承接
  - 点击一般、成交不错 → 人群准，封面继续优化
  - 主图/封面负责把人带进来，详情页负责让人相信，**两边不许各说各话**
- 每条发布前过《本地化手册》两份自检清单；音乐只用泰国本地热榜。

## 第4步 冷启动测什么：漏斗+样本量（开店后执行）

冷启动目标**不是好看的销售数字，是回答三个问题：谁愿意买、因为什么买、最大成交阻力是什么。**

TikTok内容电商漏斗诊断表（哪环掉得最狠先修哪环）：

| 症状 | 病根 | 动作 |
|---|---|---|
| 播放/曝光低 | 内容覆盖不足、hashtag/关键词偏、发布时间 | 换钩子、补38个泰语词矩阵、测发布时段 |
| 播放高、商品点击低 | 视频和产品关联弱、钩子骗播 | 前3秒出产品+痛点，砍掉无关剧情 |
| 点击高、加购低 | 价格/卖点/详情/零评价信任 | 详情补证据；首批单引导图文好评 |
| 加购高、不成交 | 运费、COD信任、时效、**结账税费惊吓** | 见下方专项；FAQ前置 |

🔴 **我们的特殊成交阻力（文章没有、2026泰国新政造成）**：买家点499结账时被平台代收关税+VAT，实付587-641฿（+18-28%），极易在支付页弃单。应对：
1. 视频和详情前置"ราคารวมภาษีนำเข้า（含税到手价）"心智，或直接把标价心理锚点设计为"含税价"表达；
2. 开店第一天用后台关税计算器核实本品定10%还是20%档（模型5个待核验假设之一）；
3. 监控"加购→支付"转化，若税费弃单严重，评估是否微调挂牌价让实付落在心理价位（需重算模型，不许拍脑袋降价）。

**测试周期看样本量不看天数**：低客单一天可积累样本，但数据被拆太散就只能凭感觉。同期只跑少量内容组合，每组攒够可对比的播放/点击样本再判去留。

**完播率作为分发信号（2026-11-03补，K5，来自 AI 五步法蒸馏）**：
- 看**完播率**不看播放量。完播率是平台判断「这条值不值得推」的核心信号，播放量只是结果。
- 原案例（美区付费）的做法是「定向投给看完 95% 的人」，我们零付费用不了；**反向用同一个信号**：哪条完播率高 → 说明钩子对 → 拆它的前 3 秒结构、节奏、结尾引导 → 用同结构复制下一条，加大自然分发。
- 执行：每条视频记录完播率，每周挑完播率最高的那条拆结构。这是我们的"加预算"动作的替代品——不花钱，花结构复制的力气。
- 注意：数据 T+7 滚动刷新，有滞后，**不用前 3 天数据下结论**（据万里Tk 全托管 AIGC 篇）。

## 第5步 有正反馈再放大（我们的放大规则）

放大前置条件：连续出现稳定点击、加购和**真实成交（且每单有利润）**。
1. 先找有效组合：哪类视频（A/B/C哪组）、哪个选题、哪个车型场景、哪个SKU（35#引流、50#利润）成交质量高、退款低；
2. **复制验证过的选题结构**（换车型/换场景重拍），这是我们的"加预算"动作；
3. 达人按≤8%佣金逐个加，先小后多，拒收率/退款率超标的达人停；
4. 健康标准（改写文章原句适配我们）：内容成交增加的同时，**搜索、推荐带来的自然访问同步增长**——说明链接在摆脱对单条视频的依赖；
5. 每次放大同时看三件事：成交成本（我们这里=样品/素材/佣金让价）、退款拒收率、单笔净利。GMV涨而单笔亏损=立即刹车。

## 第6步 放量前核对后端（代发模式版，11.11前必做）

文章：很多新品不是死在冷启动，是死在刚有起色、后端接不住。我们无库存但不等于无风险：
- [ ] [供应商A]35#现货深度与日产能力书面确认；大促前7天起每日问库存
- [ ] 二供绿创/怡雅韵同材质同款建档可切换（主供断供48h内顶上）
- [ ] 1688跨境铺货链路首单试跑全通过：17:00截单、邢台→义乌仓、运费随单预付、中性无中文包装
- [ ] 大促前核义乌仓出库时效与泰国尾程运力高峰
- [ ] 泰语客服FAQ+差评回应模板备好（温和、不争辩、mai pen rai；覆盖尺寸/异味/物流/税费4类高频）
- [ ] 赠品规则、发货时效写进详情，避免活动中反复确认
- [ ] 拒收/不良损失每周回填模型，实际vs假设（拒收8%/不良1%）偏差>3个点就重算定价

## 第7步 爆款之后（复利沉淀）

1. **经验资产化**：记录哪类素材成交质量高、用户最关心什么、哪个SKU引流/哪个出利润——反向喂给下一轮选品和脚本；
2. **评价区+客服咨询是金矿**：相同问题反复出现→回主图/详情提前解释；某场景被反复提到→围绕它继续产内容（不机械换促销文案）；新差评→进《痛点库》v2，作为ODM改款输入（引擎B护城河）；
3. **关联款只补同一场景的后续需求**：已规划的2个布艺折叠款（侧袋/椅背挂等）11月中下旬只建档、主推日出3-5单后上；不为提客单强行组合；
   - **关联款选品标准（2026-09-20据"反光座垫+雨衣"案例补）**：优先选 ①轻、②国内拿货极便宜、③解决泰国本地强痛点（暴晒烫/雨季/堵车）、④能与35#同包发出 的**高毛利小配件**。这样它单卖要承担全套货代+运费不划算，但搭主品同发时集采+运费摊薄=边际成本极低、毛利厚。
   - **战术定位=主品的利润缓冲/价格战防御**：未来35#被跟卖或平台逼促销时，主品价格让到竞品持平保流量，用配件高毛利填回让出的利润（案例：雨衣让2元、配件赚6元，整体反多4元、单量+15%）。靠组合守住35#不陷入纯价格战，符合"利润优先"。
   - **纪律**：冷启动期主推链接未跑通前不上配件、不分散精力；捆绑须是真实可搭配的组合（平台组合装规则），不做虚假捆绑。选品视角多问一句"什么好搭配着卖"，但不脱离35#使用场景。
4. 持续看自然流量、转化率、单笔利润、库存周转；流量衰减时先诊断是市场热度下降、竞争加剧还是内容失鲜，再决定优化、延伸还是退出；
5. 泰国站稳定日出10-20单后，按《备选市场对比》开马来西亚子店——**重新走一遍本SOP第1-4步**（补马来四方验证、建马来话术库、独立本地化），不把泰国结论平移。

## 第8步 商品卡与日常排查（2026-09-20据TikTok起量资料蒸馏，只取执行层）

> 来源资料以"日出50单、达人+Shopping广告放大"为目标（美区大店打法）。**其单量目标和付费放大我们不套用**——守住零付费广告、达人≤8%纯佣、利润优先。只吸收以下4块与我们不冲突的执行细节：

1. **商品卡三优化（上架即做，不照搬供应商图）**
   - 主图：首图纯白底、完整展示全貌；附图依次为 使用场景→核心功能→细节特写→尺寸对比→真实效果
   - 标题：结构=核心产品词+当地常用属性词+使用场景词+规格词；关键词从商城前端搜索下拉词、后台商品机会找，只留高度相关的
   - 价格：新品无评价背书，不直接定高价，用优惠券/限时折扣/多件组合提竞争力（仍不破盈亏模型底价）
2. **信号链接：资源不撒胡椒面**
   - 标准：累计≥3单 **且** 之后仍有持续曝光/点击/订单；3单只是观察，关键看能否持续、成交后有无利润
   - 对信号链接做**单变量测试**：一次只改一个（主图角度/标题词/详情顺序/优惠方式/定价/库存），对比前后点击/转化/利润
3. **重复铺货红线（合规）**：同一商品不建多条只改标题/图/SKU/价的相似链接抢流量——可能被判重复铺货而降权；颜色/尺寸/数量等真实差异在原商品内做变体；差异化放在内容表达和卖点呈现上
4. **每日四数据排查（对应第62行漏斗）**
   - 曝光降 → 查标题关键词/类目归属/属性完整/库存
   - 点击降 → 查主图、价格竞争力、首屏卖点、竞品变化
   - 成交降 → 查详情说服力、评价数量、运费设置、配送时效
   - 利润降 → 重算采购/物流/佣金/广告/售后全成本[见本地台账]. **上架≠被看见：先查收录再谈转化（2026-09-20补）**
   - 新品没成交，先排除最早的故障：回后台数据分析/商城与搜索页，确认商品**是否被收录、有无曝光、曝光来自哪个入口**；没进入分发路径时猛发视频=发给没打开的入口
   - 链条：商品提报通过 → 被商城/搜索收录 → 才可能有曝光（不机械等"4-8h/48h"旧经验，看后台状态实际变化）
   - **五列诊断表**（每个新品建一张）：信息状态（类目/规格/库存/履约是否完整）｜推荐状态（是否收录、主入口）｜流量数据（曝光/点击/加购/成交）｜本次改动（只改一个变量）｜下一步（观察/重测/停止）
   - 停止条件：信息完整、收录正常、展示稳定却仍无点击/加购 → 回到需求与商品表达重新审视，不无限改封面
   - 主图只保留一个最核心利益点（让人秒懂解决什么问题）；AI可协助整理关键词/视觉草案，但类目、功效宣称、真实规格须自己确认，不搬运竞品图
