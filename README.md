## 笔记规范

每篇笔记带 Obsidian frontmatter，字段：`type / status / created / tags / models / countered / applies_to / one_liner`。
状态流：`distilling`（蒸馏中）→ `applied`（已用于真实决策）→ `archived`（归档）。
笔记入库流程：AI 出草稿，人审定后入库——**人做决策，AI 做苦力**。
