# 《毛泽东选集》读书笔记：用实践找主要矛盾

> 副题：第一性原理视角下的毛泽东思想蒸馏。
> 版本范围：《毛选》第一至四卷（人民出版社）、两篇哲学著作《实践论》《矛盾论》为核心，兼及《毛主席语录》与毛思想研究文献。
> 一句话定位：**他的全部方法论可以归结为一件事——通过实践不断逼近事物的主要矛盾，然后集中全部资源解决矛盾的主要方面，再用新的实践检验，循环上升。**

---

## 一、为什么他的方法至今有效：第一性原理视角

一切行动的失败，归根到底只有两类：一是**认错了矛盾**（在打不该打的仗），二是**解决了矛盾的次要方面**（抓小放大，忙而无功）。

毛泽东思想的第一性拆解：

1. **世界的本质是矛盾的运动**：事物内部矛盾双方的对立统一推动一切变化。不承认矛盾，就是否认变化本身。
2. **认识只能来自实践**：知识不是从书本和权威那里"得到"的，而是从实践中"长"出来的。实践—认识—再实践—再认识，循环往复以至无穷。
3. **矛盾有主次，且互相转化**：任何复杂系统同时存在多个矛盾，其中必有一个在现阶段起主导作用（主要矛盾）；一个矛盾的两方面也有主次（矛盾的主要方面）。**解决主要矛盾的主要方面，次要矛盾会迎刃而解或显著缓解。**
4. **具体情况具体分析是活的灵魂**：矛盾有普遍性（事事有矛盾），更有特殊性（每个矛盾的构造不同）。照搬别人的解法 = 刻舟求剑。

这四条在物理层面是自洽的：系统有结构、结构有瓶颈、瓶颈主导行为、瓶颈随条件转化。这与现代系统工程、约束理论（Theory of Constraints）完全同构。

## 二、实践论：知识只能从实践中长出来

### 2.1 核心命题
- "通过实践而发现真理，又通过实践而证实真理和发展真理。"
- 认识的过程：感性认识（接触事物，获得片面的、现象的材料）→ 理性认识（去粗取精、去伪存真、由此及彼、由表及里，得出规律）→ 再回到实践中检验、修正。
- "真理的标准只能是社会实践。"
- 反对两种人：**教条主义**（拿现成公式到处套）和**经验主义**（把局部经验当普遍真理）。

### 2.2 第一性原理推论
1. **没有调查就没有发言权**。任何判断先问：我的材料是从哪里来的？是亲手摸过，还是听人转述？
2. **先干起来，才知道路对不对**。纸上推演一万次不如真实环境下试错一次——成本最低的信息获取方式就是实践本身。
3. **复盘是把实践转成认识的唯一通道**：做完必须"去粗取精、去伪存真、由此及彼、由表及里"十六字加工，否则经历只是经历，不是经验。
4. **敢于承认认识错误**："不预存任何的成见，随时愿意根据新的实践修正结论"，这是实事求是的内核。

### 2.3 落到工作：实践四循环
```
接触实际（获取一手材料）→ 加工十六字 → 形成判断 → 实践检验 → 修正判断 → 进入下一轮
```
任何项目、任何战略，跑不出这个环；停下来不转，就是教条主义或经验主义的开始。

## 三、矛盾论：主要矛盾，及矛盾的主要方面

### 3.1 核心命题
- 矛盾存在于一切事物的发展过程中；每一事物的发展过程中存在自始至终的矛盾运动。
- 复杂事物中**多种矛盾并存，必有一种是主要矛盾**，它的存在和发展规定或影响其他矛盾。
- 一个矛盾的两个方面中，**必有一方处于支配地位（矛盾的主要方面）**，事物的性质主要由它决定。
- 矛盾双方在一定条件下互相转化：主要矛盾可能降为次要，次要可能升为主要；胜利方也可能转为失败方——条件是人为创造的。

### 3.2 与马斯克/芒格体系的对应（同构验证）
| 矛盾论 | 现代管理/系统理论 |
|---|---|
| 主要矛盾 | 约束理论：系统产出由瓶颈决定 |
| 矛盾的主要方面 | 第一性原理：找到唯一约束墙，全攻它 |
| 矛盾转化 | 临界点/相变；十倍目标后的路径切换 |
| 具体情况具体分析 | 能力圈 + 芒格"用多种模型交叉验证" |
三套体系在物理上指向同一件事：**找出此刻真正卡住系统的那一颗螺丝。**

### 3.3 操作定义
- 每周/每阶段，强制回答三个问题：
  1. 当前有哪些矛盾？（全部列出来，不许合并省略）
  2. 哪一个是主要矛盾？（用标准：哪个矛盾解决了，其他矛盾会明显缓解或被转化？）
  3. 这个主要矛盾里，哪一方面是主要方面？（攻这一面，而不是平均用力）
- 主要矛盾会**随阶段转化**：井冈山时期是"生存"，延安时期是"发展+整风"，建国后是"建设"。业务同理：0-1 阶段主要矛盾是"有没有人真的要"，1-10 是"交付可不可复制"，10-100 是"组织跟不跟得上"。阶段一变，主要矛盾必变；用上一个阶段的解法打下一个阶段的仗，是最常见的死法。

## 四、《毛选》中的九个实战原则

### 4.1 集中优势兵力，各个歼灭敌人
- 不被全局劣势吓住：全局可以劣势，局部必须优势。十倍投入打一点，打完再打下一个。
- 创业对应：资源永远不够，不要全线铺开。选**一个细分战场做到局部垄断**，再复制。

### 4.2 战略上藐视敌人，战术上重视敌人
- 战略层保持必胜信念（矛盾会转化，形势比人强）；战术层把每个细节当硬仗打。
- 对应：vision 要大到没人信，执行细到每个按钮的颜色。

### 4.3 你打你的，我打我的
- 主动权是战争的命脉：决不在敌人选定的战场、敌人规定的时间、敌人希望的方式作战。
- 对应：不和巨头拼对方的主场。找到对手"不得不打"而"打得难受"的战场。

### 4.4 不打无准备之仗，不打无把握之仗
- 但对"把握"的定义要来自调查和实践，而非恐惧。
- 对应：每个 bet 写清楚"赢的条件、输的信号、可承受的代价"。

### 4.5 持久战：阶段论
- 任何大目标都分阶段：防御 → 相持 → 反攻。每个阶段有自己的主要矛盾和自己的打法。
- 对应：拒绝"毕其功于一役"的规划。给每个阶段单独定目标、单独配资源、单独定判据。

### 4.6 统一战线：团结一切可以团结的力量
- 主要矛盾决定统一战线：谁是我们的敌人，谁是我们的朋友，是革命的首要问题。
- 对应：分清此刻真正的对手（主要矛盾的对方），把非主要矛盾方转化为合作方。友商、渠道、甚至旧势力，都能是下一阶段的盟友。

### 4.7 自力更生为主，争取外援为辅
- 把主动权建立在"别人不帮我能不能活"上。
- 对应：核心业务、核心数据、核心交付能力，必须自握（与马斯克垂直整合原则同构）。

### 4.8 群众路线：从群众中来，到群众中去
- 正确的路线只能从用户的真实实践中来，再回到用户实践中去检验。
- 对应：创始人必须泡在一线。脱离用户的战略家必然滑入教条主义。

### 4.9 批评与自我批评
- 组织持续进化的机制：公开指出问题，不以人废言，就事论事。
- 对应：复盘会只归因模型，不归因人格（与芒格复盘法官同构）。

## 五、毛泽东思想 × 第一性原理：蒸馏后的七条

1. **矛盾是万物之本**：业务停滞、人生困顿，根子上都是矛盾在积累未被正视。先承认矛盾，才谈得上解决。
2. **实践是认识的唯一来源**：所有"我觉得"，都必须降级为"我测过"。
3. **主要矛盾决定方向**：列出全部矛盾，找出那一个"解决它其他就缓解"的；找不到就不行动。
4. **矛盾的主要方面决定打法**：同一个矛盾，攻错了面等于没攻。
5. **阶段决定任务**：主要矛盾随阶段转化，解法必须逐阶段重构；把过去的成功当未来的地图，是教条主义。
6. **矛盾双方互相转化**：强可转弱、弱可转强，条件是人为创造的——统一战线、集中兵力、持久战都是创造条件促成转化的工具。
7. **具体情况具体分析是唯一活的原则**：以上六条，到具体场景必须重新落地一次，否则又是新的教条。

## 六、行动清单（本周可用）

**业务版**
- 写下当前业务全部矛盾（≥7 条），圈出主要矛盾，标出它的主要方面；本周 80% 精力只投给主要方面。
- 选一条你正在执行的"计划"，回溯源头的判断是来自实践还是来自类比/权威；来自后者的，安排一次最便宜的真实测试。
- 给每个在跑项目写"阶段判断"：它在防御期/相持期/反攻期？打法与资源匹配吗？

**人生版**
- 写下人生当前全部矛盾（事业/健康/关系/现金流/学习…），找出主要矛盾——通常那个让其他一切变难的问题，就是它了。
- 给主要矛盾的主要方面定一个 90 天可验证的实践目标，写清楚验证方式和放弃信号。

**AI 流水线接口**
- 矛盾列表节点：定期让 Agent 汇总全部矛盾清单并投票排序主要矛盾。
- 实践检验节点：任何来自"类比/权威"的判断，强制生成一次最小成本实测。
- 阶段诊断节点：每月让 Agent 对照业务指标，判断主要矛盾是否已转化，解法是否需重构。

## 七、十条咒语（背诵版）

1. 没有调查，没有发言权。
2. 实践—认识—再实践—再认识，转起来才算活着。
3. 先列全部矛盾，再挑主要矛盾。
4. 解决矛盾先攻其主要方面。
5. 阶段一变，矛盾必变，打法必换。
6. 矛盾双方互相转化，条件是造出来的。
7. 全局可以弱，局部必须强。
8. 你打你的，我打我的；我的战场我定。
9. 把主动权握在自己手里，外援是锦上添花。
10. 具体情况具体分析，一切从实际出发。
