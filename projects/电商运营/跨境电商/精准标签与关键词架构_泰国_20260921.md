# 精准标签与关键词架构（泰国TikTok·35#）

> 建档 2026-09-21。起因：主人问"我们的精准标签是什么？是否已被别人占？"
> 核心结论：品类词/人群词/痛点词都占不了（通用、靠内容养），**唯一能被法律占走的是品牌名/商标，必须开店前查重**。

## 一、三层标签

| 层级 | 泰语标签 | 可被独占？ |
|---|---|---|
| 品类/搜索 | กล่องเก็บของท้ายรถ、ที่เก็บของท้ายรถ、กล่องพับได้、จัดระเบียบท้ายรถ | 否（通用，但拥挤） |
| 人群 | รถเก๋ง（轿车）、Vios/Yaris/City/HR-V/Revo 车主、家用通勤 | 否（靠成交养） |
| 痛点/需求 | แข็งไม่ยุบ（硬挺不塌）、ไม่ลื่นขณะเบรก（急刹不滑）、กันรั่วกันน้ำ（防漏防水） | 否（系统按内容/成交关联） |

## 二、关键词策略：弃大词，打细分

- ❌ 不投大词：กล่องเก็บของ、อุปกรณ์รถยนต์（泛流量，系统无法识别人群）
- ✅ 主攻精准组合：**กล่องเก็บของท้ายรถ รถเก๋ง พับได้ แข็งไม่ยุบ**
  （轿车专用·折叠·硬挺不塌）→ 进来即"轿车车主+被塌箱坑过"的高转化人群
- 我们的标签心智一句话：**不是"收纳箱"，是"轿车专用、硬挺不塌、急刹不滑的折叠后备箱箱"**
- 护城河=产品证据（全侧壁2.5mm插板）+内容持续打同一标签，让系统固化人群；非靠注册

## 三、赛道在架品牌（别人已占的品牌词，勿用）

- SEAMETAL、HOTOR、NeatBox、KNODEL（2026-09-21搜索所见）
- 它们占的是：①商标品牌词 ②先发的搜索位与评价积累（非法律独占）

## 四、品牌名查重（开店前必做，硬动作）

- [ ] 定一个简短、泰语好读、无含义/宗教冲突的品牌名
- [ ] 泰国查重：DBD 商业发展厅（名索）+ IP Thailand 商标库
- [ ] 中国侧同步查重，避免与国内在先权利冲突
- [ ] 确认无人注册后再用于开店、账号；跑量后尽早注册泰国商标
