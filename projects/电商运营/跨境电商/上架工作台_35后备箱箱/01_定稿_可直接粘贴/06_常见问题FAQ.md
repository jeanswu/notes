# 06 常见问题 FAQ【已定稿 · 已泰国母语审校 2026-10-12】

> 一问一答，泰语可直接粘贴。答案只承诺能兑现的（依泰审风险表逐条降级）。

**Q1: พับเก็บได้จริงไหม? บางแค่ไหน?**（真能折叠吗？多薄？）
```
A: พับเก็บได้ค่ะ บาง ไม่เกะกะเมื่อไม่ใช้งาน ช่วยลดการใช้พื้นที่จัดเก็บ
```

**Q2: ใส่ของแล้วจะยุบไหม?**（装东西会塌吗？）
```
A: มีแผ่น PP หนา 2.5 มม. เสริมทั้ง 4 ผนัง และแผ่นรองก้นแข็ง ช่วยให้กล่องคงรูปได้ดีในการใช้งานทั่วไปค่ะ
```

**Q3: ใช้กับรถของฉันได้ไหม?**（我的车能用吗？）
```
A: ออกแบบมาสำหรับรถเก๋งค่ะ โปรดตรวจสอบขนาดพื้นที่ท้ายรถเทียบกับขนาดสินค้า 35 × 35 × 30 ซม. ก่อนสั่งซื้อ
```

**Q4: กันน้ำไหม?**（防水吗？）
```
A: ผลิตจากผ้า Oxford 600D เช็ดทำความสะอาดง่ายค่ะ หากโดนน้ำควรเช็ดให้แห้งโดยเร็ว ไม่แนะนำให้แช่น้ำ
```

**Q5: ใส่ของหนักได้แค่ไหน?**（能放多重？）
```
A: เหมาะสำหรับจัดเก็บของใช้ทั่วไปภายในรถ เช่น ของใช้เด็ก สัมภาระ และอุปกรณ์ดูแลรถค่ะ
```

**Q6: มีกลิ่นไหม?**（有味道吗？）
```
A: หากเพิ่งแกะสินค้า แนะนำให้ผึ่งลมสักครู่ก่อนใช้งานค่ะ
```

**Q7: ขนาดเท่าไหร่? น้ำหนักเท่าไหร่?**（尺寸和重量多少？）
```
A: ขนาดกางออก 35 × 35 × 30 ซม. ความจุประมาณ 36 ลิตร (ค่าประมาณจากขนาดสินค้า) น้ำหนักประมาณ 0.96 กก.
```

---
**定稿说明（依泰审风险表）**
- Q2/Q5 不给具体承重，限定"日常使用/一般车内物品"。
- Q3 不保证具体车型适配，引导买家自行核对后备箱尺寸。
- Q4 只说易擦拭、不建议泡水，不用"กันน้ำ（防水）"。**2026-11-05 实物泼水实测不防水，答案已加「遇水尽快擦干」，不得改回任何防水表述。**
- Q6 不承诺"无异味"，改为"新箱建议通风后使用"。
- Q7 数字与规格表统一：0.96กก.、约36ลิตร（估算）。
